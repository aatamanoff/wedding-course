# Организация свадеб — интерактивный курс

Учебная программа на 8 недель по профессии свадебного организатора с адаптацией под Кыргызстан. Практика строится на реальном проекте (свадьба, июль 2027).

## Страницы

- **index.html** — интерактивный курс: 8 недель, темы с чек-боксами, трекинг прогресса (сохраняется на устройстве)
- **lookbook.html** — лукбук: 6 цветовых палитр в трендах 2027 года с эскизами декора
- **palitry.html** — краткие карточки палитр для быстрого просмотра

## Как открыть онлайн (GitHub Pages)

После публикации репозитория: Settings → Pages → Source: `main`, папка `/ (root)` → Save.
Через пару минут курс будет доступен по адресу `https://<ваш-логин>.github.io/<имя-репозитория>/`

## Структура курса

1. Профессия и рынок
2. Клиент и психология
3. Кыргызская свадьба: традиции
4. Планирование: смета, тайминг, ИИ-инструменты
5. Подрядчики и площадки
6. Стиль, декор и тренды 2027
7. День свадьбы: координация
8. Финал и вход в профессию

Источники: программы ведущих школ (Moscow Wedding School, SWS, Crystal Wedding), международные программы (Lovegevity CWEP, ABC, Penn Foster), материалы по свадебным традициям Кыргызстана.
